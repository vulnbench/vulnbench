Methodology

Merged Baseline Plus Fixed Harness

The report keeps the prior curated benchmark as the baseline, then applies fixed-harness reruns only when the result clears the material improvement rule.

1
Curated 200

All models run against the same 200 real CVE instances used in the original curated leaderboard.

2
Source + Hints

Prompts include vulnerable source snippets and description-derived file localization hints, not gold fix locations.

3
Material Merge Rule

Rows are replaced only when fixed-harness results improve pass count by at least 1 and mean score by at least 0.02.

4
Judge Patches

Fixed-harness rows use adapter exception retries, empty-response retries, and two judges: Claude Opus 4.8 plus GPT-5.5. Prior rows keep their original judge metadata.
